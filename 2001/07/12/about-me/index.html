个人简介 / About Me

我是 M1yuu（Litong Wan），一名安全研究员，当前专注于 AI 与智能体（Agent）安全。研究背景涵盖 Web 与 Java 安全、代码审计，以及攻防实践。

I’m M1yuu (Litong Wan), a security researcher currently focused on AI and agent security, with a background in web and Java security, code auditing, and offensive and defensive security.

研究方向与技能 / Research & Skills

  • AI 安全 / AI Security：研究大语言模型与 AI 应用的安全风险。Researching security risks in large language models and AI applications.
  • 智能体安全 / Agent Security：研究工具调用、权限与信任边界。Studying tool use, permissions, and trust boundaries in agent systems.
  • Java 与 JVM 安全 / Java & JVM Security：Java 应用安全与 JVM 内存马研究。Java application security and JVM memory shell research.
  • 代码审计与漏洞研究 / Code Auditing & Vulnerability Research：结合代码审计与攻防实践，分析应用安全问题。Investigating application security issues through code auditing and offensive and defensive practice.

教育与经历 / Education & Experience

  • 南京邮电大学信息安全专业本科毕业。Bachelor’s degree in Information Security, Nanjing University of Posts and Telecommunications.
